stay comparable and nothing gets re-tried blind.

## Column definitions

- **Experiment ID**: `EXP-NNN`, zero-padded, monotonically increasing, never reused.
- **Date**: ISO format (YYYY-MM-DD).
- **Objective**: one sentence — what question this experiment answers.
- **Features used**: exact list/reference to the feature set version (link to
  `feature_registry.md` entries by name).
- **Model**: algorithm + library version if relevant.
- **Validation strategy**: exact CV scheme (e.g. "Repeated 5-fold x10, seed=42").
- **Hyperparameters**: exact values or a link to the config file used (`configs/`).
- **RMSE**: mean ± std across folds/repeats, not a single split's number.
- **Runtime**: wall-clock time for the full experiment.
- **Key findings**: what changed, what surprised us, what confirmed a prior hypothesis.
- **Next action**: the specific next experiment this motivates — never leave this blank.
